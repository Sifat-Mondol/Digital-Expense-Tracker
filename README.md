# Digital Expense Tracker

This is a simple Android application for tracking expenses and income. 
It allows users to add, edit, and delete expenses and incomes.

## Features:
✔️ Add new expenses  
✔️ Add new incomes
✔️ View expense history
✔️ View income history
✔️ Delete unnecessary expenses  
✔️ Delete unnecessary incomes  
✔️ Show total balance of user after incomes and expenses
✔️ Simple UI design
